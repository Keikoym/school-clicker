# School Clicker

Jogo escolar do tipo clicker desenvolvido em Godot 4.7 e GDScript. Ganhe QI estudando, compre melhorias e materiais para a mesa e enfrente as duas provas existentes.

## Abrir o projeto

Importe `project.godot` na Godot 4.7. O projeto foi validado com Godot 4.7.1. A cena inicial é `menu_principal.tscn`.

Ainda não há um executável validado neste repositório; o executável vazio encontrado no projeto original não foi incluído.
